# Privacy

The supplied app has no account system, analytics SDK, advertising, tracking cookies, or backend for collecting study records. Its fonts and interface assets are local.

Reviews, answers, test history, notes, saved terms, personal glossary corrections, and resource bookmarks are stored in your browser using localStorage. This is not encrypted storage. Other people using the same browser profile can access the record. Clearing site data removes it. Private browsing may discard it when the session ends.

The optional suggestion box keeps its draft only in memory while the page is open. Open email draft hands the category and message you enter to your email app, addressed to amirlobe@usc.edu; you review and send it there. It does not automatically attach study history, scores, or browser details. Copy message puts the draft on your clipboard when allowed. The app does not use a form-submission service or send feedback itself.

Exports create JSON files on your device. Imports read a selected file locally and replace the browser's existing record after confirmation. The app does not upload these files. Keep backups out of public repositories.

The app runs on one browser origin at a time. Moving between a local file, localhost, a GitHub Pages address, or a custom domain does not automatically transfer progress. It does not synchronize across devices.

GitHub operates the hosting service for a Pages deployment and logs visitor IP addresses for security purposes. See https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages and https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement . Opening a linked external resource also contacts that website and is subject to its own policies.

Any future addition of analytics, accounts, advertising, or synchronization requires updating this notice to describe the actual behavior.
